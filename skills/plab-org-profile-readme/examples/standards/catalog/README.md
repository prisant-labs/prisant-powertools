## Tools

Tools for tidying and building projects.

### [alpha-tool](https://github.com/example-org/alpha-tool)

*🟢 Stable*

![release](https://img.shields.io/github/v/release/example-org/alpha-tool?display_name=tag&style=flat-square) ![license](https://img.shields.io/github/license/example-org/alpha-tool?style=flat-square)

Stop losing files in cluttered project folders. The tool sorts a folder by rules you write once.

**Recent releases:**

- [v1.2.0](https://github.com/example-org/alpha-tool/releases/tag/v1.2.0) (Oct 2026): Adds a dry-run mode that shows every move before it happens.
- [v1.1.0](https://github.com/example-org/alpha-tool/releases/tag/v1.1.0) (Aug 2026): Rules can now match on file age.
- [v1.0.0](https://github.com/example-org/alpha-tool/releases/tag/v1.0.0) (Jun 2026): The first stable release.

### [beta-kit](https://github.com/example-org/beta-kit)

*🟡 Beta*

![release](https://img.shields.io/github/v/release/example-org/beta-kit?display_name=tag&style=flat-square) ![license](https://img.shields.io/github/license/example-org/beta-kit?style=flat-square)

Write a small editor plugin without starting from nothing. The kit supplies settings, commands and a test harness.

**Recent releases:**

- [v0.4.0](https://github.com/example-org/beta-kit/releases/tag/v0.4.0) (Sep 2026): Adds a settings panel helper.
- [v0.3.0](https://github.com/example-org/beta-kit/releases/tag/v0.3.0) (Jul 2026): The first public release.
